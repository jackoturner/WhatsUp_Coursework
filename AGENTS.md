# Agent instructions

This is the shared entry point for AI assistants working in this repository.

## Rules

Before changing files, read [the repository rules](.agents/rules/repository-rules.md)
and any additional Markdown rule files under `.agents/rules/`, including
subdirectories. Follow the rules that apply to the current task.

## Skills

Skills are stored in `.agents/skills/<skill-name>/SKILL.md`. Check their names and
descriptions for relevance to the current task. Read and follow the full
`SKILL.md` for any relevant skill, loading its supporting files as needed.

The repository owner maintains the rules and skills manually.
